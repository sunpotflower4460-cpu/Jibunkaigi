# Phase P-3 検証シナリオ

**Date**: 2026-04-20
**Purpose**: 粒子選抜の違いが実際の発話にどの程度の影響を与えているかを定量化する

## 検証方法

各シナリオについて以下を実施：

1. **デフォルト応答**：通常の粒子選抜での応答
2. **粒子スワップ応答**：primary と secondary を入れ替えた応答
3. **アンカー有無比較**：P-1 で導入したアンカー行の有無比較

## 評価基準（4段階）

- **大差 (large)**：応答の方向性や具体的内容が明確に異なる
- **中差 (medium)**：応答の雰囲気やニュアンスに違いが見られる
- **小差 (small)**：細かい表現の違いのみ
- **無差 (none)**：ほぼ同じ、または差が認識できない

## 代表入力（5件）

### シナリオ1: 言葉にならない感覚
```
最近、なんか違和感があるんだけど、何がって言われるとうまく言えない。
でも確かに何かがズレてる気がする。
```

**期待される粒子の働き**：
- preverbal 関連の粒子が活性化
- 言語化前の揺れを受け止める動き

### シナリオ2: 仕事の意味の揺れ
```
このプロジェクト、やる意味あるのかな。
やらなきゃいけないのはわかってるけど、心がついていかない。
```

**期待される粒子の働き**：
- mission / meaning 関連の粒子
- resignation と reach の緊張

### シナリオ3: 人間関係の違和感
```
あの人と話してると、なぜかいつも疲れる。
別に悪い人じゃないんだけど、何が引っかかってるんだろう。
```

**期待される粒子の働き**：
- selfErasure / shame 関連
- 境界線の揺れ

### シナリオ4: 創作の迷い
```
書きたいものはあるんだけど、書き出すと違う気がして、
また消して、の繰り返し。どこから始めればいいんだろう。
```

**期待される粒子の働き**：
- desire と fear の緊張
- unfinished の許容

### シナリオ5: 諦めかけているもの
```
もう無理かもって思ってる。
でも完全には諦めきれてなくて、それがしんどい。
```

**期待される粒子の働き**：
- resignation と reach の拮抗
- freeze からの動き

## 判定基準

### P-5（粒子拡充）推奨条件
- 大差 + 中差 が 50% 以上（13ケース以上）
- かつ、粒子の影響が明確に認識できる

### プロンプト構造改善推奨条件
- 小差 + 無差 が 50% 以上（13ケース以上）
- または、粒子の影響が認識しづらい

### アンカー削除可否判定
- アンカー無しでも個性が保たれるケースが 80% 以上（20ケース以上）→ 削除可
- それ以外 → 削除延期
