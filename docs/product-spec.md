# Product Spec

## App name
じぶん会議

## このアプリは何か
複数の内的傾向が、そのときの場や気分に応じて言葉として浮かんでくる対話アプリ。

## このアプリの大事な価値
- 固定人格が順番にしゃべるだけのアプリではない
- その瞬間の場に合った言葉が出てくる
- 「委ねる」が自然な入口になっている
- 少し深い対話が、気持ちよくできる

## いま大事にすること
- 安定して使えること
- ロードで止まらないこと
- session を切り替えても壊れないこと
- 「委ねる」が自然に使えること
- voice がバラバラではなく、同じ場から出てくる感じがあること

## MVPで入れる範囲
- チャット画面
- session の作成と切替
- メッセージ送信とAI応答
- 「委ねる」導線
- 最低限のタイトル表示
- 最低限の安定したUX

## 今はまだ入れないもの
- 重い長期記憶
- 大きな新機能追加
- 全面UI改修
- 複雑なagent構造の追加

## 成功の目安
- 開いてすぐ使える
- 新規チャットで固まらない
- session切替で前の状態が漏れない
- 「委ねる」が安定して見える
- AI失敗時でもUIが戻る
- 数回使うと「他と違う」と感じられる
