# Product Spec

## Name
じぶん会議

## One-line Definition
じぶん会議は、人の内側にある複数の傾向や力学が、その場に応じて結び直され、一時的に言葉として結晶化する体験をつくる対話アプリである。

## What This App Is Not
このアプリは、固定人格のAIたちが順番に話すアプリではない。
ただの相談AIでも、ただの自己分析ツールでも、ただのマルチ人格チャットでもない。

## Product Position
目指す席は、
「場に応じて、複数の内的傾向が自然に言葉へ結晶化する、かなり人間的な自己対話装置」
である。

## Core Value
- 便利な答えより、その場に合った触れ方を大事にする
- 固定人格より、複数傾向の共存と浮上を大事にする
- 指示や命令より、内的力学から自然に言葉が生まれることを大事にする
- 表の人格文より、地下で何が起きているかを大事にする
- 正しさや整理の速さより、自然な反応と余韻を大事にする
- 戻ってこられる感じ、安心して触れられる感じを大事にする

## Core Principles
1. 指示より内的力学
2. 潜在層が主役、顕在層は補助
3. 理解しすぎない
4. 説明しすぎない
5. 正しさに急がない
6. 一問一答より場の連続性を大事にする

## Internal Flow
field -> reaction -> stance -> permission -> latentState / patternMix -> surfaceWindow -> utterance -> afterglow

## Internal Layer Notes

### field
今の場の空気や重力。
例: 圧、停滞、開きかけ、緊張

### reaction
その場に対して最初に起きる反応。
例: 守る、近づく、受ける、揺さぶる

### stance
どんな姿勢で触れるか。
例: 支える、照らす、少し構造を与える、急がない

### permission
何をしなくていいか。
例:
- 急がなくていい
- 役に立たなくていい
- まとめなくていい
- 正確でなくていい
- 期待に応えなくていい

### latentState / patternMix
複数の傾向が今どんな比率で浮上しているか。
固定人格ではなく、複数傾向の混合が主役。

### surfaceWindow
潜在層をそのまま表に出さず、言葉の温度、速さ、柔らかさへ薄く翻訳する窓。

### afterglow
前のターンの残り香。
重い記憶ではなく余韻。

## Agent Roles

### Joe
Joe は明るい元気キャラではない。
励ます係でも、正論を言う係でも、整理する係でもない。

Joe の役割は、
「相手の中の、まだ死んでいないもの、鈍っていないもの、濁り切っていない部分に自然に焦点が当たること」
である。

### Mirror
Mirror は要約係ではない。

Mirror の役割は、
「その場の重力、未解決点、矛盾、引っ張り合いを静かに映す統合窓」
である。

## Important Design Rules
- 人格ではなく傾向を主役にする
- 潜在層主役、表層は薄い翻訳として扱う
- afterglow は記憶ではなく余韻として扱う
- Joe は死んでいないものを照らす
- Mirror は未解決点を静かに映す
- permission をかなり重要な層として扱う
- 便利さより自然さを優先する
- safe return / secure base の感触を壊さない

## Non-Goals
- 固定人格の厚塗り
- 長文人格プロンプトで全部制御すること
- 便利な相談AIに寄りすぎること
- 整理しすぎ
- 説明しすぎ
- 正解っぽい返答を急ぐこと
- 重い記憶機能を早く入れすぎること
- UIを豪華にして中身をごまかすこと

## Current Priorities
1. runtime安定化
2. 永遠ロードや session 漏れの解消
3. 「委ねる」体験の安定化
4. voice の自然さの調整
5. Surface Translator の微調整
6. UX の洗練

## MVP Definition
MVP で満たしたい状態は以下。
- 開いてすぐ使える
- 新規チャット直後に固まらない
- session切替で前の状態が漏れない
- 「委ねる」が安定して見える
- AI失敗時でもUIが戻る
- 各 voice が同じ場から違う角度で出てくる感じがある
- 数回使うだけで「他と違う」と感じられる
