# Visual Art Direction — Vinus-craft

## 概要

このドキュメントは Vinus-craft の基本ビジュアル方針を定義します。
色・光・霧の設計は `src/game/visual/` に集約し、コード中への散在を防ぎます。

---

## 1. 基本ビジュアル方針

### 目指す空気

Vinus-craft の空気は、地球的な爽やかさではなく、
**金色文明の残光が霧に溶けたような空気** を目指します。

**キーワード:**
- 金白 / 白金 / 琥珀
- 淡い霧 / 重い暗部
- 青白い結晶光 / 乳白の湿度
- くすんだ古代金 / やわらかい残光

### 避ける方向

| 避けること | 理由 |
|---|---|
| 原色っぽい黄色 | 金星らしさが失われる |
| 地球の青空 | 世界観と合わない |
| 全体がベタッと黄色い | 奥行きが出ない |
| 暗部がただ黒い | 発光素材が映えない |
| 霧が白一色で平坦 | 詩性がなくなる |
| 地域ごとの差がない | 世界の広さが伝わらない |
| 発光素材がネオンのように派手 | 品位が失われる |

## 3. Venus Golden Mist プリセット

**ID:** `venus_golden_mist`  
**日本語名:** 金霧の金星

### 設計意図

Vinus-craft 全体の基本プリセット。
白金・琥珀・金白の淡い霧でまとめ、くすみすぎず、明るいがまぶしすぎない。

### 設定値

| 項目 | 色 / 値 | 備考 |
|---|---|---|
| sky top | `#F5ECD4` | 淡いクリームゴールド |
| sky mid | `#E8D4A0` | 薄い琥珀 |
| sky horizon | `#EDE4C8` | 白金霧 |
| sky lowerMist | `#E0D0A8` | 霧と混ざる金 |
| fog base | `#EDE8D8` | 薄い金白 |
| fog density | 0.02〜0.15 | 奥行き表現、視界妨害にしない |
| ambient color | `#F0E8D0` | やわらかい白金 |
| ambient intensity | 0.65 | 平坦にならない強さ |
| sun color | `#FFF5E0` | 白金 |
| sun intensity | 1.1 | 暖かい・まぶしすぎない |
| shadow tint | `#3A2A10` | 深い茶金 |

## 5. 空の色設計

空は単色ではなく、グラデーションで設計します。

```
上空:  淡い金白 / 薄いクリーム  (#F5ECD4)
中間:  やや琥珀                (#E8D4A0)
地平線: 白金霧                 (#EDE4C8)
下部:  霧と混ざる金             (#E0D0A8)
```

- 青空にしない
- 黄色すぎない
- 白っぽく飛びすぎない
- 霧と自然につながる

地平線 (`horizonColor`) は地域ごとに軽く変更し、
遠景が霧に溶けていく印象を出します。

## 6. 霧の設計

### 設計原則

霧は視界妨害ではなく、**奥行き表現** として使います。

| 距離 | 霧の使い方 |
|---|---|
| 近距離 | 薄く・見やすい |
| 中距離 | やわらかく色が乗る |
| 遠距離 | ゆっくり消える |

### height fog

簡易 height fog で高度による差をつけます:
- 谷底: 霧が濃い
- 丘の上: 霧が薄い
- 洞窟入口: 低く霧が残る

## 7. 光の設計

### ambient light

| 場所 | intensity | 意図 |
|---|---|---|
| 白金平地 | 0.72 | 神々しい明るさ |
| Venus Golden Mist（基本） | 0.65 | 標準 |
| 霧の谷 | 0.60 | 柔らかい |
| 古代遺跡 | 0.55 | くすみ |
| 黒金裂け目 | 0.35 | 暗いが輪郭は残る |
| 結晶洞窟 | 0.30 | 暗い中で発光が映える |

### sun light

- 白金色 (`#FFF5E0`)
- 暖かい、でも黄色すぎない
- 遺跡や丘のシルエットを出す

## 8. 暗部の扱い

### 方針

- `shadowTint` で暗部にわずかな色を残す
- 黒画面にしない
- 発光素材の光が道標になる
- 霧や反射で奥行きを出す

### 地域別 shadowTint

| 地域 | shadowTint | 印象 |
|---|---|---|
| 白金平地 | `#3A2A10` 深い茶金 | 柔らかく |
| 黒金裂け目 | `#1A1428` 暗い灰紫 | 重い |
| 結晶洞窟 | `#182030` 深い青灰 | 澄んだ暗さ |
| 古代遺跡 | `#3C2A14` くすんだ茶金 | 乾いた暗さ |

---

## 9. 明暗差の美しさ

Vinus-craft の魅力は明るい場所と暗い場所の差にあります。

| 地域 | 明るさ | 印象 |
|---|---|---|
| 白金平地 | 明 | 神々しい |
| 見晴らしの丘 | 明 | 世界の広がり |
| 霧の谷 | 中 | 柔らかく霞む |
| 古代遺跡 | 中 | くすんだ残光 |
| 黒金裂け目 | 暗 | 重い深部 |
| 結晶洞窟 | 暗 | 澄んだ暗さ |

---

## 10. スマホ視認性への配慮

- 重い bloom・volumetric fog・多数 particles を避ける
- 発光素材は emissive で軽量に表現
- 暗部でも輪郭が見える（shadowTint 活用）
- 霧密度は視認性を壊さない範囲に設定
